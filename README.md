# Job Application Workflow

Prompts and helper tools for a contract-job search. Everything works on one Excel tracker. Nothing is sent or applied to automatically, except Dice applications from `dice-auto-apply/`, and only in rounds you approve.

| Folder | What it is | Start with |
|---|---|---|
| [`application-workflow/`](application-workflow) | Prepare for the vendor call, generate a resume, and draft the recruiter email, with a tracker viewer | [`application-workflow/README.md`](application-workflow/README.md) |
| [`dice-auto-apply/`](dice-auto-apply) | Optional (Module 05): apply to Dice jobs that have a resume, by asking your AI assistant in plain English | [`dice-auto-apply/README.md`](dice-auto-apply/README.md) |

Never commit a filled-in tracker or candidate profile; they contain personal data. `.gitignore` blocks the usual files, but check before you push.
